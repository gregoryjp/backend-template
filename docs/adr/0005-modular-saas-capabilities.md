# ADR 0005 — Optional SaaS capabilities

Status: Proposed, 2026-09-30.

The supplied Django SaaS video advertises reusable business capabilities without full contracts. Add these incrementally to the current Node.js/Express/TypeScript/Prisma/PostgreSQL/npm template per docs/specs/saas-platform.md. Start with organizations; keep billing and AI optional and provider-driven. Global administration and tenant membership are separate. Documentation never counts as implementation. Each module needs migration, contract, tests and review before marked complete.
